# Smart Work Assistant

Smart Work Assistant is a desktop productivity application built with **Electron, HTML, CSS, and JavaScript**. It combines productivity tools with creative visual elements to provide an interactive desktop experience.

## Features

* To-Do List
* Reminders
* Pomodoro Timer
* Weather
* Quick Web Search
* Website Shortcuts
* Desktop Notifications
* Multiple Themes
* Animated Characters and GIFs

## Tech Stack

* HTML
* CSS
* JavaScript
* Node.js
* Electron
* npm

## Run the Project

Make sure **Node.js and npm** are installed.

Open the project folder in VS Code and run:

```bash
npm install
npm start
```

After running `npm start`, the Electron application window will open automatically.

## Create Windows Setup

To create the Windows installer, run:

```bash
npm run build
```

Once the build is complete, open the **`dist`** folder.

Find the Windows **`.exe`** setup file and run it to install the application.
